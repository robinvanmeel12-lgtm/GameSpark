# GameSpark

GameSpark is a school project for managing a game collection.

## Features

- Add, edit, and delete games.
- Track games with a status: Wishlist, Owned, Playing, or Completed.
- Give games a rating from 1 to 5.
- Filter games by platform, genre, status, and rating.
- Show game thumbnails.
- Prevent duplicate games with the same name and release year.
